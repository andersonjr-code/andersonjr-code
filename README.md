Sou estudante do 3º semestre de **Análise e Desenvolvimento de Sistemas** na UNIASSELVI, com conclusão prevista para dezembro de 2027, e formado como **Técnico em Informática** pela QI Escola e Faculdade.

Também trabalho em projetos de desenvolvimento web, aplicações móveis, automação e soluções para ambientes industriais. Busco oportunidades de estágio ou nível júnior em Banco de Dados, desenvolvimento back-end e áreas de tecnologia com possibilidade de evolução para DBA.

## Projetos práticos

### Oficina OS — Ordens de Serviço industriais

Aplicação web criada para substituir registros em papel e facilitar o cadastro e a consulta de Ordens de Serviço. O sistema registra informações de clientes, projetos, materiais, quantidades, tempos, responsáveis, status e anexos.

- **Tecnologias:** React, Supabase, PostgreSQL, SQL e pgAdmin
- **Prática de banco:** consultas SQL, conexão administrativa, alterações de esquema e migrations
- **Status:** aplicação funcional e publicada
- **Demonstração:** [Oficina OS](https://oficina-os-industrial.andersonjrcode.chatgpt.site)

### Sistema de gestão industrial

Evolução de uma aplicação para rotinas de Lean Manufacturing, com módulos de ativos, Ordens de Serviço, manutenção e passagem de turno. O trabalho incluiu integração com banco, autenticação, perfis de acesso e preparação dos dados para uso real.

- **Tecnologias:** React, TypeScript, Vite, Supabase/PostgreSQL e Vercel
- **Prática:** integração entre aplicação e banco, regras de acesso e cadastro seguro de usuários

### ProCore Mobile

Aplicativo Android em desenvolvimento, criado com React Native/Expo e banco PostgreSQL no Supabase. A primeira etapa inclui autenticação por e-mail e senha, recuperação de acesso e perfis de usuário.

- **Status:** em desenvolvimento
- **Tecnologias:** React Native, Expo e Supabase/PostgreSQL

### Inspeção dimensional com visão computacional

Protótipo de laboratório para medir peças industriais capturadas por uma câmera em rede e classificá-las conforme uma tolerância definida.

- **Tecnologias:** Python, OpenCV e câmera Hikvision
- **Prática:** calibração de pixels para milímetros, região de interesse e classificação de peças
- **Status:** protótipo de laboratório
